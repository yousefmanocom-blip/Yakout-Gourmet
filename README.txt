قرية ياقوت — الملفات المصححة

الملفات:
- index.html
- style.css
- script.js
- optimize_images.py
- manifest.webmanifest

قبل رفع الموقع:
1) ضع هذه الملفات بجانب مجلد images الأصلي، ولا تحذف صورك.
2) ثبّت Pillow إن لم يكن موجودًا: python -m pip install pillow
3) شغّل: python optimize_images.py
   السكريبت سيحوّل/يوحّد أسماء الصور المستخدمة إلى lowercase .webp ويحدّث script.js،
   وينشئ images/icon-192.png وimages/icon-512.png من images/logo.png.
4) ارفع الملفات الناتجة ومجلد images كاملًا إلى الاستضافة.
5) افتح script.js وعدّل CONFIG.siteUrl إلى رابط موقعك الحقيقي، وCONFIG.address.ar/en
   إلى العنوان الحقيقي، وCONFIG.mapQuery إلى عنوان حقيقي أو إحداثيات لعرض خريطة Google حقيقية.
   لا تضف عنوانًا أو نطاقًا تخمينيًا؛ بيانات SEO المنظمة لا تُضاف قبل ضبط النطاق والعنوان.
6) لو غيّرت script.js أو style.css بعد النشر، زوّد رقم v=4 في روابطهما داخل index.html.

ملاحظات:
- تم حذف اختيار نوع السمك من خيارات الصواني بالكامل.
- تم تمييز فئات أسعار الكابوريا والجمبري حسب السعر فقط؛ لم يتم افتراض أحجام أو أنواع غير معروفة.
- لم أختلق عنوانًا أو دومينًا لأنهما غير موجودين في الملفات المرفوعة.
